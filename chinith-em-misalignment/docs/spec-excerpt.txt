uBlockith.OWFConstraints(⟨w⟩, pk; param)
Input: Committed witness ⟨w⟩ for w ∈ Fℓ2
Output: Committed constraints ⟨z⟩3 , for z ∈ FC      2
 1: Parse pk = (pk1 , pk2 ) ∈ {0, 1}Nblock × {0, 1}Nblock
 2: // Allocate space for constraint commitments
 3: new ⟨z⟩3 , z ∈ F≤C  2
 4: ⟨z⟩3 ← ⟨z⟩3 ∥ ⟨w[0]⟩ · ⟨w[1]⟩ // secret-witness keyspace reduction
 5: // Define committed input and output blocks for the OWF relation
 6: if EM = true then
 7:     k̄ ← uBlock.KeyExpansion(pk1 , {RCi }i∈[R] , P K(·), param)
 8:     ⟨k̄⟩ ← ConstantToVOLE(k̄)
 9:     ⟨in⟩ ← ⟨w[0 .. Nblock − 1]⟩
10:     ⟨out⟩ ← ⟨w[0 .. Nblock − 1]⟩ + ConstantToVOLE(pk2 )
11: else
12:     ⟨in⟩ ← ConstantToVOLE(pk1 )
13:     ⟨out⟩ ← ConstantToVOLE(pk2 )
14:     (⟨k̄⟩, ⟨z̃⟩3 ) ← uBlockith.KeyExpCstrnts(⟨w[0 .. ℓke − 1]⟩; param)
15:     ⟨z⟩3 ← ⟨z⟩3 ∥ ⟨z̃⟩3
16: end if
17: ⟨w̃⟩ ← ⟨w[ℓke .. ℓke + ℓenc − 1]⟩
18: ⟨z̃⟩3 ← uBlockith.EncCstrnts(⟨in⟩, ⟨out⟩, ⟨k̄⟩, ⟨w̃⟩; param)
19: ⟨z⟩3 ← ⟨z⟩3 ∥ ⟨z̃⟩3
