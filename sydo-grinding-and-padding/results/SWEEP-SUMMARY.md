## 判读

- Optimized 实现：**0 次接受**。R1（BAVC 开启填充零检查缺失）确认为 Reference 实现独有。
- Reference 实现：接受次数恰为 填充字节数 × 8，覆盖一段连续字节的全部 8 位，该区间外 0 次 ⇒ R1 是 Reference 实现唯一的单比特可锻面。
- 注：填充区不在签名末尾（bavc_open 之后还有 chall3/ctr 等字段），故上表的区间起点由实测接受字节导出。
- 补充签名按每参数集 20 个候选中填充最长者挑选，填充长度为首轮签名的 2–4 倍；结论不随所选签名改变。
